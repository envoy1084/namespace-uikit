# ENS Components

ENS Components is a growing collection of React components, TanStack Query
hooks, and typed contract actions for integrating ENS v2 into applications.

## Install

```bash
npm install ens-components @tanstack/react-query@5.101.2 viem wagmi
```

Import the package stylesheet once at the application root:

```css
@import "ens-components/styles.css";
```

The application must provide Wagmi, TanStack Query, and `EnsProvider`. Start
with the provider guide, then choose a component or use the lower-level hooks
and actions to build a custom flow.

## Current network

ENS v2 support currently targets the Sepolia testnet deployment. The
`"mainnet"` network value is reserved but is not implemented yet.
