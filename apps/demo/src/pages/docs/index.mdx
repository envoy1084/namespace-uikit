# ENS Components

ENS Components provides React components, TanStack Query hooks, and typed
contract actions for ENS v2.

Use the components for complete user flows. Use hooks for application-specific
interfaces. Use actions when the caller should own query and transaction
orchestration.

## Features

- Register and renew second-level `.eth` names.
- Read and update resolver records.
- Discover resolver capabilities and record permissions.
- Compose registration, approval, resolver, and primary-name transactions.
- Execute writes as single transactions, atomic EIP-5792 batches, or ordered
  sequences.
- Configure contracts and payment tokens for an ENS deployment.

## Network support

The built-in `testnet` configuration targets the ENS v2 Sepolia deployment.
Mainnet is reserved until an ENS v2 mainnet deployment is available.

Use a [custom configuration](/docs/guides/custom-configuration) for another
compatible deployment.
